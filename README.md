# 📸 Automated Attendance System

## 🚀 Overview
A project that automates student attendance using **face recognition**.  
Teachers take a **single group photo**, and the system automatically detects and marks attendance.

---

## ⚡ Features
- Upload one group photo of students.  
- Detect and recognize faces.  
- Auto-mark attendance in the database.  
- Simple teacher dashboard to view records.  

---

```bash
# Clone the repository
git clone https://github.com/Shakthivelk24/Automated-Attendance-System-.git

# Navigate to project folder
cd Automated-Attendance-System

# Install dependencies for client
cd frontend
npm install

# To Start the  Frontend
npm run dev

# Install dependencies for server
cd server
npm install

# To Start the Server
npm start

```
## 💭 Thought

This project was built with a vision to bridge the technology gap in rural education.  
By combining simplicity, affordability, and automation, our goal is to reduce teachers’ workload,  
improve record accuracy, and ensure that every student is counted — every day.  
Even with limited resources, technology can empower schools to be more efficient and connected.
